# Truth-Trace
This is my dissertation project and is fake news detector.
This project idea was inspired as to help people differentiate the difference between fake news and real news. With the use of AI on the rise so has an increase of fake news articles This is due AI being able to create such articles and web pages extremely quickly.
This project will be based on spotting the difference between those articles and tell the user whether or not the article is fake.
This will be available as a Chrome extension as it is the most used browser world-wide.
